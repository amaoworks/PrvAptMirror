三步接入 APT

以下命令需要 root 或 sudo 权限。请把示例中的发行版与代号替换为你的实际系统。
  1. 01

    安装仓库签名公钥

    公钥只授权这个仓库，不写入系统全局信任库。

    sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https:///repository-key.gpg \
  | sudo tee /etc/apt/keyrings/prvaptmirror.gpg >/dev/null
  2. 02

    添加软件源

    下面以 Ubuntu Noble 为例；其他系统可从下方选择对应的路径和代号。

    echo 'deb [signed-by=/etc/apt/keyrings/prvaptmirror.gpg] https:///ubuntu noble main' \
  | sudo tee /etc/apt/sources.list.d/prvaptmirror.list
  3. 03

    刷新索引并安装

    仓库接入后，软件包与系统其他来源一样由 APT 管理。

    sudo apt update
sudo apt install <package-name>

DISTRIBUTIONS

选择系统家族

发行版代号必须与仓库中已经发布的代号一致；它不能只根据 DEB 文件自动判断。
UBU

Ubuntu

路径 /ubuntu，例如 Noble 24.04。

deb [signed-by=/etc/apt/keyrings/prvaptmirror.gpg] https:///ubuntu noble main
DEB

Debian

路径 /debian，例如 Bookworm 12。

deb [signed-by=/etc/apt/keyrings/prvaptmirror.gpg] https:///debian bookworm main
LMD

LMDE

路径 /lmde，例如 LMDE 7。

deb [signed-by=/etc/apt/keyrings/prvaptmirror.gpg] https:///lmde lmde7 main

提示：如果 apt update 返回 404，请先向仓库管理员确认该系统代号是否已经发布。不要使用 trusted=yes 或已弃用的 apt-key 绕过签名校验。

A

公开下载、管理控制与签名执行使用独立权限域。
